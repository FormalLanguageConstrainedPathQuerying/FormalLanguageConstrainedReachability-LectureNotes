# Literature (работа с литературой)

1. Если нужен текст статьи для анализа — сначала проверь наличие в `papers_pdf/` (название файла = название статьи). Для извлечения текста — возможности модели или `pdftotext`.
2. Если статьи там нет — только тогда попробуй скачать. Получилось — добавь в `papers_pdf/` (название файла = название статьи). Не получилось — обязательно сообщи.
3. Если нужно создать новую библиографическую запись — сообщи. Не сочиняй записи самостоятельно.

Статус библиографии (что скачано / используется) — в `docs/papers.md`.
