# User Guidance Transfer

Когда пользователь даёт указание по дизайну/содержанию (разбиение, система обозначений, подход), зафиксируй его **дословно** в issue задачи или в `tasks/detailed_plan.md` как авторитетный источник, прежде чем продолжать.

## Правила
- Записывай дословно, без перефразирования.
- Помечай как авторитетное решение (например, секция `### <Тема>` в Design Notes).
- Дальнейшие решения по этой теме сверяй с зафиксированным указанием.
