# Reusing (переиспользование)

Перед созданием нового ищи существующее, которое можно переиспользовать или обобщить.

## Чек-лист
- Есть ли уже подходящий объект (граф, грамматика, регулярное выражение, автомат, пример)? Используй его, а не придумывай новый.
- Есть ли уже определение/теорема/лемма с таким же или близким содержанием? Используй его (см. `docs/book-structure.md`).
- Есть ли уже фигура/стиль/команда, которую можно переиспользовать? (см. `tex/styles/`, `figures/`.)
- Можно ли обобщить существующее, чтобы покрыть и новый случай?

## Цель
- Сквозные примеры для всей книги (см. `exposition`).
- Единый source of truth: каждая вещь описана ровно один раз; остальное — перекрёстные ссылки.
