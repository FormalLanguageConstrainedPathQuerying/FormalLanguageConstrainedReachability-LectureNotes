# Paper Integration (интеграция статей)

Некоторые разделы книги пишутся на основе наших же статей; при переносе текст может потребовать существенной доработки (унификация терминов/определений, изменение структуры под разделы книги). Результирующий текст должен быть таким же целостным и корректным, как в статье.

Полные правила — в `docs/paper-integration.md`:
- обозначения, определения, термины (единые на всю книгу; сверка с `docs/glossary.md`);
- список литературы (проверка дублей, переводы записей);
- вёрстка (пакеты, стилевые настройки в `tex/styles/`);
- перевод (термины по `docs/glossary.md`, строгий академический русский);
- перенос содержимого (алгоритм → раздел, эксперименты → раздел сравнения, введение/related work → вводные части).

Если термин/определение/библиографическая запись неоднозначны — уточни через Question tool.
