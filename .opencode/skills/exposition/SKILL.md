# Exposition (структура изложения)

1. Не разделяем текст на подразделы, если иное не указано явно. Вместо подразделов — связанные абзацы с гладкими переходами.
2. Максимально переиспользуем примеры: если можно использовать уже введённые объекты (граф, грамматику, регулярное выражение), используем, а не придумываем новые. В идеале — сквозные примеры для всей книги.
3. Примеры должны быть связаны: если в одном примере было преобразование А→Б, то при построении примера обратного преобразования покажи Б→А.
4. Определения выносятся в соответствующие разделы первых двух частей.
5. Текст строгий: для определений, теорем и т.д. — окружения `definition`, `theorem` и т.п.
6. Примеры — через окружение `example`. Очень большие сложные примеры могут выделяться в отдельный подраздел.
