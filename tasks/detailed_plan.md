## Общая геометрия (все четыре рисунка)

Таблица разбора показана повёрнутой на 45°. Ячейка $(i,j)$ отображается в точку
$P(i,j) = \big(\frac{i+j}{2},\ \frac{j-i}{2}\big)$. Обратное: $i = x - y$, $j = x + y$.

- Треугольник таблицы (валидные ячейки $0 \le i < j \le n$): вершины
  $BL = P(0,1) = (0.5, 0.5)$, $TOP = P(0,n) = (n/2, n/2)$, $BR = P(n-1,n) = ((2n-1)/2, 0.5)$.
- Основание — диагональ $i+1=j$ (прямая $y = 0.5$); левый край — ось $j$ ($i=0$, прямая $x=y$); правый край — ось $i$ ($j=n$, прямая $y = n - x$).
- Подматрица с вершиной $(a,b)$ и размером $s$ — ромб с углами:
  левый $P(a-s, b)$, нижний $P(a, b)$, правый $P(a, b+s)$, верхний $P(a-s, b+s)$.
- Условия вписанности: $a - s \ge 0$, $b + s \le n$.
- «Заземлённая» подматрица $G(x, s)$ (нижний угол на диагонали): углы
  нижний $(x, 0.5)$, левый $(x - s/2, 0.5 + s/2)$, правый $(x + s/2, 0.5 + s/2)$, верхний $(x, 0.5 + s)$.

Цвета — палитра `tex/styles/tikz.tex` (MyBlue, MyPurple, MyGray, MyRed, MyYellow), оттенки подбираются под оригинал при верификации. Подписи-идентификаторы — `\texttt{...}` (как в оригиналах). Математические метки — в math mode.

**Верификация каждого рисунка** (обязательно перед коммитом):
1. Standalone-рендер: обёртка `\documentclass[tikz,border=5pt]{standalone}` + `\usepackage[table]{xcolor}` + `\input{tex/styles/tikz.tex}` + `\input{<файл рисунка>}` → lualatex → pdftoppm → PNG (в `/tmp/opencode/`).
2. Визуальное сравнение рендера с оригинальным PNG (оба изображения смотрятся моделью), итерации до максимального сходства.
3. Инкрементальная сборка книги (`latexmk` из `tex/`) — без ошибок.

**Замена в тексте** (для каждого рисунка):
`\includegraphics[width=0.7\linewidth]{.../figures/02_Valiant/<name>.png}` →
`\resizebox{0.7\linewidth}{!}{\input{part_02_Foundations/chapter_07_ClassicalParsing/figures/02_Valiant/02_Valiant_<name>.tex}}`
+ удаление соответствующей строки `\mytodo{Перевести в TikZ}`.
PNG-файлы **оставляются** (референс; удаление — отдельная задача после мержа).

**Spec (геометрия финализирована в S6 — см. там баг макроса и тюнинг линий/меток):**
- Единица координат = диагональ белого квадрата (ячейки). Треугольник: вершина $(7,8)$, основание $y=0$, боковые края под $45°$; clip $(7,8)$--$(-1,0)$--$(15,0)$.
- Каждая цветная фигура — объединение **трёх настоящих квадратов** (поворот $45°$, равные диагонали), касающихся в точке $S$: нижний угол верхнего $T$ = правый угол нижнего-левого $L$ = левый угол нижнего-правого $R$ = $S$. Квадрат с центром $(cx,cy)$ и полудиагональю $r$: углы $(cx,cy\pm r)$, $(cx\pm r,cy)$. Для фигуры с $S=(x,y)$: центры $T=(x,y+r)$, $L=(x-r,y)$, $R=(x+r,y)$.
- Объединение — **шестиугольник** (плечи $T$ коллинеарны верхним рёбрам $L$/$R$): вершины $(x,y+2r)\to(x+2r,y)\to(x+r,y-r)\to(x,y)\to(x-r,y-r)\to(x-2r,y)\to$ замыкание. Рисуется единой заливкой с внешним контуром (без внутренних рёбер), как в оригинале.
- Ряды (снизу вверх), все фигуры **обрезаны по треугольнику** (clip):
  1. Белый ряд: одиночные квадраты, центры $(x,0.5)$, $x=0,\dots,14$ (15 шт.), $r=0.5$. Без заливки (в оригинале прозрачные, только контур).
  2. Оранжевый ряд, метка `1`: $S=(x,1)$, $x=1,3,\dots,13$ (7 фигур), $r=0.5$.
  3. Серый ряд, метка `2`: $S=(x,2)$, $x=3,7,11$ (3 фигуры), $r=1$.
  4. Розовый ряд, метка `3`: $S=(7,4)$ (1 фигура), $r=2$.
- **Взаимное зацепление** (проверено): V-вырез фигуры ряда $k$ совпадает с верхним пиком фигуры ряда $k-1$ (напр. вырез розового $(9,2)\to(7,4)\to(5,2)$ = верх среднего серого); фигуры не пересекаются — только общие границы.
- **Цвета** — полупрозрачные заливки оригинала (alpha = 99/255 → `fill opacity=0.388`), исходные RGB: оранжевый $(211,85,0)$, серый $(111,139,144)$, розовый $(255,41,211)$. Белые квадраты без заливки.
- Порядок отрисовки: белый, оранжевый, серый, розовый.
