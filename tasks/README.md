# Tasks (планы задач)

Директория для планов задач. Source of truth для активного плана живёт здесь и зеркалируется в соответствующий issue комментарием.

- `global_plan.md` — глобальный план активного **батча** связанных задач (создаётся при настройке батча, см. скилл `planning`). Зеркалируется в hub-issue комментарием с первой строкой `<!-- global-plan -->`.
- `detailed_plan.md` — детальный план **одной** задачи, разбитый на атомарные сабтаски (S1, S2, ...). Зеркалируется в task-issue комментарием с первой строкой `<!-- detailed-plan -->`.

Форматы и правила — в скилле `planning`.

Простые задачи (без планирования) сюда не попадают — они размечаются прямо в тексте через `\mytodo` (см. `planning`).
