# Сборка

Книга собирается через `latexmk` с движком `lualatex`. Всё, что ниже, выполняется из директории `tex/`.

## Команды

| Задача | Команда (из `tex/`) |
|---|---|
| Полная / инкрементальная сборка | `make` |
| Очистка промежуточных файлов | `make clean` |
| Полная очистка (включая PDF) | `make dist-clean` |
| Форматирование (latexindent) | `make format` |

Цель `make` вызывает ровно ту же команду, что и `tex/Makefile`:

```
latexmk -lualatex -synctex=1 -interaction=nonstopmode -file-line-error -shell-escape FormalLanguageConstrainedReachabilityLectureNotes.tex
```

CI собирает книгу lualatex + biber + несколько проходов — см. `.github/workflows/main.yml` (tikz externalization в CI отключена, см. комментарий в главном файле).

## Полная vs инкрементальная сборка

- **Полная сборка долгая**: lualatex + biber (библиография) + несколько проходов по всей книге, плюс компиляция всех tikz-фигур. Занимает много минут.
- **Инкрементальная сборка быстрая**: `latexmk` пересобирает только то, что изменилось. Нерисованные tikz-фигуры кэшируются в `tex/figures/externalized/` (tikz externalization), поэтому повторные сборки их не перерисовывают. Именно поэтому инкрементальная пересборка после небольшой правки заметно быстрее полной.

## Фоновый режим с автоподхватом изменений (`-pvc`)

`latexmk` умеет работать в фоне и автоматически пересобирать документ при изменении входных файлов. Это удобно для итеративной работы: запускаешь один раз, редактируешь `.tex`, и сборка подхватывает изменения сама.

Команда (из `tex/`), запускать в фоне:

```
latexmk -lualatex -pvc -view=none -interaction=nonstopmode -shell-escape FormalLanguageConstrainedReachabilityLectureNotes.tex
```

- `-pvc` — preview-continuous: следить за входными файлами и пересобирать при изменении.
- `-view=none` — не запускать GUI-вьюер (headless; агенту вьюер не нужен).
- Остальные флаги — те же, что в обычной сборке.

Практически: запусти процесс в фоне (background-задача), редактируй файлы — PDF в `tex/` обновляется автоматически. Когда работа закончена, заверши процесс (SIGINT/SIGTERM).

## Политика сборки

- Не гоняй полные clean-сборки посреди задачи — это дорого.
- Для обратной связи во время работы используй **инкрементальную** сборку (`make`) или **фоновый `-pvc`-watcher**.
- **Одну полную сборку делай в конце большой задачи**, чтобы убедиться, что вся книга собирается чисто (особенно если трогал библиографию, стили в `tex/styles/` или добавлял новые tikz-фигуры).
- Если сборка упала — читай `tex/FormalLanguageConstrainedReachabilityLectureNotes.log` (и `.blg` для библиографии).
