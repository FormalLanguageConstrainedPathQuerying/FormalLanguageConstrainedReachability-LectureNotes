# Карта документации (`docs/`)

Навигационная карта агентской документации. Каждый файл — source of truth для своей темы; скиллы в `.opencode/skills/` — тонкие указатели на эти файлы (и на TeX-исходники/инструменты/CI).

| Файл | Содержание | Скилл-указатель |
|---|---|---|
| `book-structure.md` | Структура книги по файлам, статусы разделов, краткое содержание | `project-navigation` |
| `glossary.md` | Перевод терминов (русский — английский), сокращения | `typography`, `paper-integration` |
| `papers.md` | Статус библиографии: какие источники скачаны / используются | `literature` |
| `ucfs.md` | Использование UCFS для построения примеров (SPPF, RSM) | `tikz` |
| `checking.md` | Чек-лист проверки текста | `checking`, `review` |
| `paper-integration.md` | Правила интеграции статей в книгу | `paper-integration` |
| `build.md` | Сборка: latexmk, инкрементальная / полная, фоновый `-pvc` | `build` |

## Как пользоваться

1. Для навигации по книге начинай с `book-structure.md`.
2. Перед использованием термина сверься с `glossary.md`.
3. Перед работой с библиографией — `papers.md`.
4. Перед сборкой — `build.md`.
